easycraps

The Easy Craps game engine as a plain, dependency-free Python library — no Gym/Gymnasium, no HTTP, no web framework. Everything on this page is the complete public surface of the package: every class, every method, every constant.

Zero dependencies Python 3.10+ Deterministic dice for tests Same engine as the live cabinet

This same engine (easycraps.Game, the lower-level class Table wraps) also backs the cabinet/backend HTTP/WebSocket API that drives the live web UI — so a Table in a script and a browser tab pointed at the cabinet are playing by identical rules. See ../../docs/RULES.md for the rules in prose, and ../../rl/GETTING_STARTED.md for an agent-building walkthrough. This page is the exhaustive reference; those two are the narrative introductions.

Install

From the easycraps/ directory (editable install, so an agent always sees the latest rules):

pip install -e .

With the test dependencies too:

pip install -e ".[dev]"
pytest

Quickstart

import easycraps

table = easycraps.Table(credit=200)
table.pass_line_bet(5)
result = table.roll()

print(result.ok, result.message)
print(table.credit, table.point, table.bets)

That's the whole interaction model: create a Table, call named bet/action methods on it, read its properties back. Every method returns an ActionResult.

Nothing outside this package needs to know about that internal split — import easycraps and everything under Quickstart works the same regardless of which submodule a name actually lives in. The split exists purely to keep each file focused and short enough to read in one sitting.

Concepts

Trigger — a named action ("place_bet", "roll", "press", ...) with a payload dict. It's the one thing everything in this project calls through: a button click in the web UI, an HTTP request, and every Table method all become exactly one Game.apply(trigger, payload) call under the hood.
Game — the low-level trigger dispatcher. Holds one GameState and one method, apply(). You normally don't touch this directly.
Table — the class you actually use. Wraps a Game and gives every trigger a friendly, discoverable method name (table.field_bet(10) instead of game.apply("place_bet", {"spot": "field", "amount": 10})). Adds zero new behavior over Game.
Bet spot key — the raw string identifying a bet ("field", "place_6", "hop_43", ...). Table's named methods build these for you; the full list is here if you want to bypass them with table.bet(spot, amount).

Escape hatch: trigger() and bet()

trigger(name: str, **payload) -> ActionResult

Fires any trigger by name — the exact power-user path the HTTP API uses. Every named method on this page is a one-line wrapper around this call. Use it directly for a trigger that doesn't have a named method yet, or when building payloads programmatically.

table.trigger("place_bet", spot="place_6", amount=5)
table.trigger("across", amount=1)
bet(spot: str, amount: float) -> ActionResult

Place amount on any raw bet-spot key. Every *_bet() method below is a thin wrapper over this.

table.bet("field", 10)      # same as table.field_bet(10)
table.bet("hop_43", 1)      # same as table.hop_bet(4, 3, 1)

Wager methods

Every method here places a bet and returns an ActionResult. Full payout math is in Payout tables and docs/RULES.md.

pass_line_bet(amount: float)

Pass Line. Wins 1:1 on a come-out 7, or when an established Point repeats before a 7. Loses on seven-out.

field_bet(amount: float)

Field. One roll. Wins on 2, 3, 4, 9, 10, 11, 12 — pays 1:1, except 2 and 12 pay double (2:1).

low_field_bet(amount: float) / high_field_bet(amount: float)

One roll. Low Field wins on 2, 3, 4; High Field wins on 10, 11, 12. Both pay 4:1.

place_number_bet(number: int, amount: float)

Place bet on number — one of 2, 3, 4, 5, 6, 8, 9, 10, 11, 12 (every non-7 number, including 2/3/11/12, which is non-standard for real craps). Wins whenever number is rolled, loses on 7, otherwise stays up.

table.place_number_bet(6, 6)   # $6 on the 6

hard_way_bet(number: int, amount: float)

Hard way on number — 4, 6, 8, or 10. Wins only if it comes up as an exact pair (e.g. 3-3 for Hard 6); loses if it comes up "easy" (any other combo summing to it) or on a 7.

craps_bet(amount: float) — "C"

One roll. Wins on 2, 3, or 12, pays 7:1. Functionally identical to any_craps_bet().

eleven_bet(amount: float) — "E"

One roll. Wins on 11, pays 14:1.

craps_eleven_bet(amount: float) — "C&E"

One roll. Splits the wager in half between Craps (2/3/12, 7:1) and Eleven (11, 14:1); each half resolves independently. Odd amounts round the half down.

any_craps_bet(amount: float)

One roll. Wins on 2, 3, or 12, pays 7:1.

seven_bet(amount: float)

Any-seven. One roll. Wins on 7, pays 4:1.

horn_number_bet(number: int, amount: float)

Single horn number — 2, 3, 11, or 12. One roll. 2/12 pay 30:1, 3/11 pay 15:1.

horn_bet(amount: float)

The combined Horn bet. One roll. Wins flat (3:1 on the whole wager) if the roll is 2, 3, 11, or 12 — a simplified "quick horn," not four separate sub-bets.

hop_bet(d1: int, d2: int, amount: float)

Exact two-die combination on the next roll — e.g. hop_bet(4, 3, 1) bets $1 on the next roll being a 4 and a 3 in either order. Doubles (1-1, 2-2, ...) pay 30:1; non-doubles pay 15:1.

table.hop_bet(4, 3, 1)   # wins on either (4,3) or (3,4)
table.hop_bet(6, 6, 2)   # wins only on double sixes

lucky_low_bet(amount: float)

Lucky Roller — Low Rolls. Every one of {2,3,4,5,6} must appear (any order, any number of rolls) before a 7. Pays 30:1. Multi-roll: stays active across rolls until it resolves.

lucky_high_bet(amount: float)

Lucky Roller — High Rolls. Every one of {8,9,10,11,12} before a 7. Pays 30:1.

lucky_all_bet(amount: float) — "Roll'Em All"

Lucky Roller — every non-7 total (2,3,4,5,6,8,9,10,11,12) before a 7. Pays 155:1.

Control methods

add_funds(amount: float)

Deposit credit. amount must be positive.

cashout()

Zero out credit (a "ticket printed" for the current balance). Rejected (ok=False) if any bets are still active or credit is already zero.

set_min_bet(amount: float)

Set the table minimum total bet required for roll() to proceed. This is table configuration, not really a player action — most agents won't call it.

reset(keep_credit: float = 0.0)

Starts a brand-new session on this Table (fresh GameState), optionally keeping some credit. Everything else — bets, point, history, hard-way counters, Lucky Roller progress — is wiped.

clear_last_bet()

Undoes the most recent bet/*_bet() call made since the last roll. Rejected if nothing was placed this turn.

clear_all_bets()

Returns every currently active bet's stake to credit. Rejected if there are no bets on the table.

double_bet()

Doubles every currently active bet, in place. Rejected if there's nothing to double or not enough credit to cover it.

repeat_last_bet()

Re-places whatever combination of bets was on the table for the previous resolved roll. Rejected if there's no previous bet or not enough credit.

toggle_set_bets()

Toggles whether Place and Hard Way bets are "working" on the next roll. When off, they neither win nor lose on that roll's resolution.

press(spot: str | None = None)

Re-bets the current stake onto spot, doubling it in place — most commonly used to press a Place bet's winnings back onto itself. If spot is omitted, defaults to the Place bet on the currently established Point. Rejected if there's no bet there yet or not enough credit.

table.press()              # press the Point's Place bet
table.press("place_6")     # press a specific spot explicitly

toggle_puck()

Cosmetic manual "OFF" toggle for the puck marker — only usable while no Point is established (table.point is None). Rejected otherwise.

roll(d1: int | None = None, d2: int | None = None)

Resolves a roll: settles every active bet against the dice, updates the Point, and appends to history. Omit both arguments for random dice; pass them for deterministic/replayable rolls (see Deterministic rolls). Rejected if there are no bets on the table, or the total is below min_bet.

table.roll()               # random dice
table.roll(d1=3, d2=4)     # forces a 7

Game class

Import as easycraps.Game. The low-level trigger dispatcher Table is built on. Use this directly only if you specifically want the raw dict-based trigger interface (e.g. building your own wrapper, or mirroring exactly what the HTTP API sends).

Game(rng: random.Random | None = None)

Constructs a fresh session with an empty GameState (zero credit).

.apply(trigger: str, payload: dict | None = None) -> dict

Dispatches a named trigger (see Trigger names). Returns a plain dict: {"ok": bool, "message": str, "state": dict} — the exact JSON shape the HTTP API's POST /sessions/{id}/trigger returns. Raises TriggerError for programmer errors (unknown trigger name, invalid bet spot, non-positive amount); returns ok: False for valid-but-rejected actions.

from easycraps import Game

game = Game()
game.apply("add_funds", {"amount": 100})
game.apply("place_bet", {"spot": "field", "amount": 10})
result = game.apply("roll", {})
print(result["ok"], result["message"])
AttributeTypeMeaning
stateGameStateThe live, mutable session state. Table reads this for every property.
rngrandom.RandomThe random source used for dice when roll isn't given explicit d1/d2.
trigger_nameslist[str]Property — every valid trigger name, for introspection.

ActionResult

Import as easycraps.ActionResult. What every Table method returns.

ActionResult is also truthy/falsy based on ok, so you can write:

    print("bet was rejected:", table.message)

TriggerError

Import as easycraps.TriggerError (subclass of ValueError). Raised for programmer errors — an unknown trigger name, an invalid bet-spot key, or a non-positive amount where one is required. See Errors vs. rejections for how this differs from a normal ok=False result.

Errors vs. rejections

Two different failure modes, on purpose:

  • Raises TriggerError — you (the programmer) did something invalid: an unknown trigger name, a bet-spot key that doesn't exist, a negative/zero amount where a positive one is required. These are bugs in the calling code, so they're exceptions, not silent failures.
  • Returns ActionResult(ok=False, ...) — the action was well-formed but rejected for a normal game reason: not enough credit, rolling before the table minimum is met, trying to cash out with bets still active, pressing a spot with nothing on it, etc. Exactly what a human player would see as a rejected action, not a bug.
try:
    table.bet("not_a_real_spot", 5)
except easycraps.TriggerError as exc:
    print("programmer error:", exc)

result = table.pass_line_bet(1_000_000)  # more than table.credit
if not result.ok:
    print("rejected, not an error:", result.message)

Deterministic rolls

Two independent ways to make outcomes reproducible:

  1. Seed the table — Table(seed=42) makes every future random roll() reproducible across runs.
  2. Force specific dice — table.roll(d1=3, d2=4) ignores randomness entirely and resolves exactly that roll. This is how easycraps/tests/test_engine.py and test_table.py pin down every scenario (come-out seven, seven-out, a specific hard-way hit, ...).
# Force a seven-out from an established point:
table.pass_line_bet(10)
table.roll(d1=2, d2=2)      # point = 4
table.roll(d1=3, d2=4)      # 7 -> seven-out, deterministic

Worked examples

A minimal round

import easycraps

table = easycraps.Table(credit=100)
table.set_min_bet(1)          # table defaults to $3; lower it for small examples
table.pass_line_bet(5)
result = table.roll()

print(result.message)
# "Point is SIX. Anything but 7 keeps it alive."
# or "7 on the come-out — Pass Line wins! Place a new Pass Line bet."

A tiny agent loop

See rl/example/q_learning_agent.py for a complete runnable Q-learning agent built on exactly this API. The core loop:

table = easycraps.Table(credit=200)
table.set_min_bet(1)

for _ in range(60):
    if table.credit + table.total_bet <= 0:
        break
    before = table.credit + table.total_bet
    table.field_bet(1)
    table.roll()
    reward = (table.credit + table.total_bet) - before
    # ... feed `reward` and whatever state you chose to your learner ...

Using the raw Game/trigger API directly

from easycraps import Game, TriggerError

game = Game(rng=None)
game.apply("add_funds", {"amount": 50})
game.apply("place_bet", {"spot": "hard_6", "amount": 1})
try:
    game.apply("place_bet", {"spot": "nope", "amount": 1})
except TriggerError as exc:
    print(exc)

result = game.apply("roll", {"d1": 3, "d2": 3})   # forces a hard 6
print(result["state"]["credit"])
